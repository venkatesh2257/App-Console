Release Gate Findings & Tickets

Actionable engineering tickets formatted with precise requirements, reasons, and remediation steps.

BLOCKER RULE-16KB-ALIGN: Native Library 16 KB Page Memory Alignment
ELF PT_LOAD Alignment
What Was Found
64-bit native library compiled with legacy 4 KB max page size (p_align < 0x4000).
Why It Blocks Release
Google Play requires 16 KB page alignment for Android 15/16. Unaligned apps crash immediately on launch with SIGSEGV/SIGBUS.
Remediation Action
-Wl,-z,max-page-size=16384 (or upgrade AGP >= 8.5.1 and NDK >= r27)
REVIEW REQUIRED RULE-PERM-INSTALL: REQUEST_INSTALL_PACKAGES Justification
Restricted Permission
What Was Found
Manifest declares android.permission.REQUEST_INSTALL_PACKAGES.
Requirement
Must have user-facing core app justification for enterprise dispatch or direct update. Requires human approval before submission.
WARNING RULE-R8-PROGUARD: Partial Deobfuscation Verification in AAB Mode
Source Code Horizon
Status
Mapping file confirmed in BUNDLE-METADATA. For full keep-rule safety and reflection verification, execute scan in Source Code Mode.
